# Test vectors

All keys, passphrases, PINs and identity files in this folder are **test material only**. They protect nothing.

* `hkem_v3.txt` – known-answer vector for the hybrid KEM (ML-KEM-1024 + ECDH brainpoolP512r1, KeyCombine).
* `identity_v11_0*` – identity files frozen from app version 11.0 (regression test: newer versions must still open them).
